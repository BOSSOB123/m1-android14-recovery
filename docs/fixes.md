# 基础系统检查

## 时间和联网状态

本例曾发现平板时钟仍在旧日期，导致 HTTPS 证书校验失败；默认联网探测地址也不可达。先纠正实际时间，再分别测试 DNS、真实 HTTPS 和联网探测。本机重连后变为 VALIDATED，用户确认无互联网提示消失。

本次历史操作使用 `connectivitycheck.platform.hicloud.com/generate_204` 作为 HTTP/HTTPS 探测地址，其当时返回预期状态不代表在其他地区长期可达，更不代表所有网站均可访问。自动 NTP 刷新未独立验证。

## 显示与性能

用户澄清进入页面时有背景颜色变化，文字图标稳定，不能据此认定为整屏闪烁。读到固定刷新率、没有明显热限制；短样本显示仍有较多错过帧。

三类动画倍率设为 0.5 后，用户报告有改善。曾试用 900×1440 / density 240，但收益不足以抵消清晰度损失，最终恢复原生 1200×1920 / density 320。动画缩短不等于实际渲染性能翻倍。

GPU 合成测试曾改善前摄界面闪烁，但可能增加功耗和负载，持久性未单独跨重启验证。相机方向与媒体输出尚无完整的系统级修复验证。

本项目范围只包括系统恢复、刷入和基础验证，不包含额外应用的安装或使用说明。
